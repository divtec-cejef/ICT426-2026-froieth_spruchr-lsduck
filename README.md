# ICT426-2026-froieth_spruchr-lsduck
Bienvenue sur le projet **LSDuck**, une plateforme e-commerce moderne dédiée à la vente de canards en plastique de collection et de bain. Ce projet a été réalisé dans le cadre du module **ICT426** à la Division Technique du CEJEF par Chris Sprunger et Ethan Froidevaux.

## 📝 Description

LSDuck est une application web complète qui permet aux utilisateurs de parcourir un catalogue de canards en plastique originaux, de les ajouter à un panier et de simuler la finalisation des achats.

### Fonctionnalités principales :
* **Catalogue de produits :** Affichage dynamique des canards disponibles et barre de recherche.
* **Gestion du panier :** Ajout, modification de la quantité et suppression d'articles en temps réel.

## 🚀 Technologies utilisées

* **Frontend :** HTML, CSS, JavaScript
* **Backend :** Fichier JSON
* **Gestion de version :** Git & GitHub
